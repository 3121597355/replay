# 收藏原句回放与音频学习

学习台可导入本地电影、美剧视频或播客、新闻、访谈音频。视频使用原播放器，音频使用专用音频播放器；支持 MP3、M4A、WAV 等常见音频格式，实际解码能力由浏览器决定。配套 SRT/VTT/ASS 字幕支持逐句循环、倍速、查词、收藏、录音跟读和导出；无字幕的音频可以播放，但本次不增加语音转文字服务。文件夹扫描也识别常见音频扩展名。

## 原句定位

收藏词或整句时，保存当前学习 session ID、素材名、字幕起止时间和来源。查词时立即捕获对应来源与 File，异步查词期间更换素材不会把收藏关联到新素材。回放使用该原片时间轴，不使用电影的原始剪辑偏移。

旧收藏没有时间点时，只在当前保存的素材字幕中唯一精确匹配原句（忽略空白差异）才补全；相同台词出现多次或匹配失败时要求重新收藏，不猜时间点。示例路径只允许随站发布的固定 sample，不从 localStorage 执行任意远程 URL。

## 本机存储

`replay-saved-media-${owner}` 独立 IndexedDB 缓存原素材，与只保留最新学习素材的原数据库分开。每次导入的 session 内多个收藏共用一份缓存；同一文件多次重新导入可能产生多个缓存。缓存保存整份原视频/音频，不剪辑、不上传。各账号空间隔离，文件名、大小、修改时间严格匹配，清理缓存或换设备需重新选择同一个原文件。

串行化读取、保存和移除，避免删除期间恢复旧缓存。空间不足时仍保存收藏文字和时间点，当前页面可用内存素材；复习可重新选择原文件。删除最后一个引用该 session 的收藏时释放收藏缓存，当前学习缓存另行保留。

## 播放行为

复习页和生词本的“播放原句”只在点击后加载本地素材。播放从字幕开始，帧检查及 timeupdate 到句尾暂停；原生控制条 seek 限制在原句范围内，素材时长不足时拒绝播放。播放新原句暂停其他视频/音频与 TTS；听单词发音暂停原句。收起、切卡、离开页面、切后台暂停，卸载释放 Blob URL。

学习统计只发送已有的固定操作和前台学习秒数，不发送文件、素材名、时间点、字幕或句子。
