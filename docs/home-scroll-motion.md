# 首页滚动入场

参考用户本机简影项目 `http://127.0.0.1:8099/` 的实际页面及其 `landing-motion.js`、`motion.js`。

- 首屏标题、说明和入口：12px 上浮，700ms，依次出现。
- 功能介绍、推荐海报、搜索筛选区域、片单结果、底部说明：32px 上浮，850ms，`cubic-bezier(.22,1,.36,1)`。
- 同排功能与片单卡片相隔 100ms，推荐海报相隔 120ms。
- 距视口底部 80px 时触发；完全离开上下 100px 的扩展边界后重新准备，回滑可再次进入。
- 搜索框与类型、难度、排序筛选作为一组入场，相隔标题 100ms。按下鼠标或触摸时暂时保持当前动画位置，松开后继续入场，避免点击过程中控件移走。键盘聚焦立即显示；加载更多按钮保持稳定位置。
- 初始遵循系统的“减少动画”设置。页面底部可开启或减少动效，选择保存在本机 `replay-home-motion` 中。
- 服务器生成的 HTML 始终可读；支持动画且脚本已初始化后才准备屏幕下方的内容。使用一组观察器处理全页，筛选和加载更多新增的卡片也会注册。

## 首屏影视背景

- 首屏全宽铺设模糊的影视混剪，依次展示《老友记》《星际穿越》《绝命毒师》《阿甘正传》《权力的游戏》。每部取 4 秒、重叠叠化 0.55 秒，总循环约 17.25 秒，末尾叠化回首镜头；不加载完整预告片。
- 使用 640×360、12fps 的动态 WebP 图片，静态 JPG 作为无脚本及加载失败时的背景。角落标注“经典电影 · 美剧片段”。首页、登录、注册和找回密码页面不创建背景 `<video>`，也不请求 MP4，避免手机浏览器把装饰视频接管成播放器。
- 素材页面、预告 URL、选取时间保存在 `scripts/home-montage-sources.json`。原始素材不提交，影片权利属于各权利人；`node scripts/build-home-montage.mjs <素材目录>` 可重新生成混剪。背景素材不属于项目 MIT 源码授权。
- 文字中心区域叠加主题色遮罩，边缘保留画面，底部渐隐；浅色与深色分别适配。
- 遵循系统减少动效设置与首页现有动效开关。减少动效或省流量模式下不加载动态图片；离开首屏、切到后台或关闭动效时卸载动态图并显示静态封面，返回后按当前偏好重新显示。
- 动态图片不经过视频播放器或自动播放权限流程。浏览器不支持该格式或请求失败时保留静态背景，页面入口继续可用。学习台、原句播放器和录音回放继续使用正常的媒体元素。

原视频方案的历史验收（2026-11-13）：Chromium 验证了 17.25 秒、约 760KB 的视频混剪及静音内联播放。2026-11-14 收到手机浏览器仍会接管背景视频的真机截图后，背景改为动态图片；原视频不再作为公开背景资源部署。

## 首屏排版

- 标题两行均为五个汉字，去掉句末标点；桌面字号随视口在 40–52px 间调整，手机 32–40px，字重 600、行高 1.25。
- 说明拆成短介绍和功能行，限制文字宽度，统一上下间距。两个学习入口等宽、46px 高，桌面宽 148px、手机宽 128px。
- 首屏内容居中并平衡留白，保留现有混剪与滚动入场。
- 2026-11-13 验证：1440px 桌面，以及对应 125% / 150% / 200% 缩放布局的 1152px / 960px / 720px 视口；390px、320px 手机视口。浅色、深色下标题均保持两行，按钮等宽等高、不重叠，无水平溢出或页面错误。缩放采用等效 CSS 视口与像素比例模拟。

## 验证

2026-11-09，本机 Edge 浏览器：

- 桌面滚动：进入前 opacity=0、translateY(32px)，滚入后 opacity=1、transform=none。
- 上滑返回后卡片重新准备，再次滚入会重播。
- 390×844 与 320×740 浏览器视口均无水平溢出；浅色、深色切换成功。
- 搜索“老友记”得到 1 个可见结果；“再看一些”由 9 部增至 18 部；作品链接打开 `/movie/friends`。
- 搜索筛选整组补上入场后，进入前 opacity=0、translateY(32px)，进入后 opacity=1、transform=none；滚入时点击并输入“老友记”得到 1 个结果，电影类型与难度选择可用。390px 视口输入“阿甘”得到 1 个结果，无水平溢出。
- 系统默认减少动画时仍可阅读内容；通过页面开关减少动效后所有等待类清除，重新开启可恢复。
- TypeScript 检查和 Next.js 生产构建通过。
- 原有配对、字幕导出、下载导入、手机浏览器兼容检查通过。

验证使用浏览器视口调整，未把它宣称为手机真机测试。
