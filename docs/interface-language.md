# 中英文界面

导航的 `EN` / `中文` 按钮切换界面语言，不重新加载页面。
英文品牌名使用 Replay English；中文名称继续为剧说英语。

首次访问参考浏览器首选语言：中文显示中文，其他语言显示英文。
用户手动选择保存在 `replay-language`，优先于浏览器设置，并通过 storage 事件
同步到同一来源的其他标签页。禁止浏览器存储时仍可在当前页面切换。

## 范围与边界

- 导航、首页、注册/登录/找回密码、学习台、录音、下载入口、账号与收藏复习支持英文。
- 学习指南、隐私条款提供英文内容；作品页提供简明英文学习说明。
- 注册、邮箱绑定和找回密码的验证码邮件跟随发起请求时的界面语言。
- 用户导入的媒体文件名、字幕原文、中文译文、词典释义和收藏内容保持原样。
- 下载页的本地组件属于独立程序；此更新翻译网站的下载入口，不更新已安装组件的内部界面。
- 管理后台保持现有中文业务内容。

`LanguageProvider` 使用 React Context；已知界面文案通过 `useLanguage().t` 或
服务器页面中的 `Text` 组件呈现，不扫描或修改字幕 DOM。消息模板支持占位参数，
插入参数原样保留。`LanguageContent` 只用于静态说明页的中英文内容切换。
不要用语言作为播放器、学习空间或表单的 key，以免切换时重置内容。

初始服务器 HTML 与首次客户端渲染均为中文，挂载后应用语言偏好，避免 hydration
不一致。没有增加外部翻译请求、依赖或账号字段。
现有 canonical URL、站点地图与百度验证保持不变；这是界面切换，尚未建立
可供搜索引擎独立收录的 `/en` 页面及 hreflang。

## 验证

2026-11-16 使用 Chromium 触屏仿真覆盖 1536×700、1107×568 电脑窗口，以及
1229×574、1024×1366、768×1024、390×667、320×568 触屏窗口。
验证首次语言、切换与刷新保持、跨页面选择、英文按钮布局、翻译设置、录音、
媒体位置/倍速/字幕保留，以及各公开页面英文内容。
本地另使用模拟邮件接口检查验证码提示和语言参数、切换后表单输入保留、
新闻音频及字幕导入恢复，以及禁止本地存储的情况下切换。
邮件 API 测试拦截所有外部请求，检查双语邮件、默认语言和验证码安全；不会发送真实邮件。

浏览器验收使用真实视口截图，不使用可能重置触屏仿真的全页截图。
仿真不能替代 Android Edge 或 iPad Safari 真机验收。
