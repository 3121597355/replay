# 2026-11-11 网站更新

用户要求的三项更新一并交付：学习台退出后的恢复、下载页说明精简、管理员后台更新日志。

学习恢复说明见 [learning-session.md](learning-session.md)。浏览器已验证：示例片段暂停在约 7.24 秒、0.75 倍速、单句循环开启、译文隐藏；离开学习台到首页后再返回以及完整刷新，视频、16 条字幕、时间和设置均恢复，保持暂停。9 组回归测试覆盖真实 File 字节持久化、状态、存储不足与导入竞争；下载导入原有 8 组检查通过。

下载页标题改为「只有链接？这里一键下载视频！」，明确是可以独立用于下载支持来源的视频、电影等内容的可选拓展。页面保留用途、已有文件导入、三步安装和一次本地保存说明；连接完成后安装说明折叠，不重复展示连接提示。下载组件源码与连接协议不变。

后台新增「更新日志」栏目，记录当前版本与已发布的后台统计、结构和图标更新。栏目沿用管理员鉴权，属于后台页面；数据由 `lib/changelog.ts` 维护，每次发布在该文件首项增加日期、版本和实际改动。日志不包含凭据、访问原始记录或私人学习内容。

本次更改不调整生产密码、密钥或统计采集口径。回滚网站代码使用普通 Git revert；浏览器缓存采用独立 IndexedDB，不修改下载临时库或云端数据库。回滚后浏览器缓存不会自动删除，可在新版学习台使用「清除记录」管理。
