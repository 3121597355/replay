# 生词卡片翻转动效

系统或浏览器报告 `prefers-reduced-motion: reduce` 时，原全站样式把所有过渡缩短为 0.01ms，卡片点击看起来像直接切换。后台旧样式还包含不限定管理页的 `transition: none !important`。

卡片翻转由主动点击触发，使用独立的动画开关，默认开启。650ms 的对称缓动让翻面过程更清楚，不受全站减少动效规则覆盖。复习页与生词本抽屉均可关闭；关闭后仍能正常查看释义与复习，只取消旋转过渡。选择保存在当前浏览器的 `replay-vocab-motion`，不上传，也不影响首页、背景视频或其他动画的偏好。存储不可写时保留当前页面内的选择。

正常动效与系统减少动效下，都需验证点击卡片、点击“翻看释义”、Enter/空格产生中间旋转状态，而不只是最终译文变化；同时验证手动关闭、重开、刷新后保留选择、手机宽度与浅深主题。后台样式仅作用于 `[data-replay-admin]`。
