# 学习台平板布局

## 问题与处理

Android 平板横屏访问 `/learn?trial=1` 时，可用窗口约为 1229 × 574。
原有 `min-width: 1024px` 样式将页面高度固定为 `100dvh`，工具栏换行后挤压播放器，
录音区和字幕操作也可能被裁切。

宽度至少 768px、支持触屏指针（`any-pointer: coarse`）的设备改为可增长的文档布局：

- 横屏使用 3:2 双栏，视频至少 240px 高，字幕栏随播放器与控制区等高。
- 竖屏使用上下布局，视频保持 16:9，字幕列表在下方独立滚动。
- 展开录音或更多工具时增加页面高度，允许向下滚动，不压缩视频。
- 在 768–1279px 窗口及触屏平板上，将次要功能折叠到“更多工具”。

布局变化只依赖 CSS；素材、字幕、倍速、循环和录音逻辑继续使用同一套组件。
较矮的横屏允许录音区位于首屏下方，以保留可用的视频高度。

## 验证记录

2026-11-15 使用 Chromium 触屏仿真，覆盖 1024×600、1229×574、1280×600、
1366×650、820×600、960×440、768×1024、1024×1366；同时回归
1107×568、1536×700 电脑窗口及 390×667、320×568 手机窗口。

检查无横向溢出、横屏双栏对齐、竖屏上下排列、播放/切句/0.75倍速/循环、
更多工具与翻译设置、录音/停止/回放/下载，以及旋转后素材保留。
本地模式另验收新闻音频与字幕导入、刷新后恢复。
