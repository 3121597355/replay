# 学习台退出恢复

用户反馈：退出学习台再进入时，之前的视频丢失，影响连续学习。原实现只按字幕指纹保存时间，视频 File、blob URL、字幕与播放设置都在组件状态内，路由离开后被销毁。

2026-11-11 更新：最近一次视频与学习状态保存到本机 IndexedDB。返回页面时重新读取 File 并创建新的 blob URL，恢复字幕、缓存译文、时间、语速、循环目标和译文开关。恢复后保持暂停，避免自动出声。模块内存快照保证路由跳转期间还未完成的磁盘写入也可恢复。

视频只保留一份，替换视频时与元数据一起原子更新，清理旧媒体。写入串行化，旧导入不能覆盖新导入；初始化读取不得覆盖用户刚选择的视频。播放中节流保存，暂停、页面隐藏和组件卸载时补写进度。没有字幕的视频也保存播放位置。

若浏览器存储不足，先保存字幕与进度，再明确提示重新选择同一个视频。恢复原视频时核对名称、大小与修改时间，保留对应字幕；不同视频按新学习会话打开，避免错配旧字幕。完全不可用的存储会显示提示，仍允许直接学习。视频缓存不上传；清除网站数据、无痕窗口关闭或更换浏览器后不能保证恢复。

「清除记录」清理当前缓存视频、字幕及其播放进度，不删除原文件、生词本或翻译接口设置。原下载导入临时库保留原协议，新学习缓存采用独立库，不改变下载组件的 15 分钟临时转交与清理逻辑。

自动测试覆盖视频字节与字幕恢复、路由期间写入、快速替换、防止初始化覆盖新导入、空间不足恢复、无字幕视频、示例视频、清理以及存储不可用。浏览器验收覆盖离开学习台再返回与完整刷新后的播放器、字幕、时间和设置。
