# 录音跟读与翻转卡片

学习台播放器控制条下方的“录音跟读 · 练口语”展开后，选择字幕句子，按“听原句 → 开始录音 → 停止录音 → 回放我的跟读录音”练习。听原句在句尾暂停；录音和回放自己的声音时原视频暂停，避免声音混在一起。切换字幕后仍保留上次录音及它对应的原句，重录成功才替换旧音频。

录音依赖浏览器 MediaRecorder 与麦克风授权，需要 HTTPS 或 localhost；优先 WebM/Opus，Safari 使用支持的 MP4，遇到拒绝授权、缺少设备或设备占用会显示明确提示。每次最长两分钟，切后台停止并保存已有录音，离开页面立即关闭麦克风；迟到的授权结果也会释放设备。音频只在页面内存处理，不上传，刷新或离开前可下载保存，支持删除。前台录音和录音回放按现有账号时间规则计入学习日历，切后台不累计。当前提供跟读和听音对比。

生词本每张卡片正面显示英文词句，背面显示已收藏的释义；无译文时提示补充。卡片支持点击、Enter 和空格翻面；发音和移除按钮在卡片外侧，Anki 导出沿用原数据。收藏复习使用同样的翻转动画与原有熟悉度计划，下一张回到正面。遵循系统减少动效设置，浅深主题分别使用网站颜色。
