# 下载器检查版本

源工具位于 `K:\work\MangaShelf\video-downloader`。本目录只复制源码、静态页面和测试；浏览器配置、Cookie、下载历史、下载文件和二进制未复制。

## 当前运行范围

这是监听 `127.0.0.1` 的本地工具。使用 Node.js 22.4 或更新版本；当前验证使用 Node.js 24。需要 FFmpeg 和 FFprobe；处理平台网页时还需要 yt-dlp，浏览器解析使用本机 Chrome/Edge。

```powershell
$env:YTDLP_PATH = '你的 yt-dlp 路径'
$env:FFMPEG_PATH = '你的 ffmpeg 路径'
node server.mjs
```

可配置 `PORT`、`DOWNLOADS_DIR`、`HISTORY_FILE`、`FFPROBE_PATH`，字幕版默认端口 45211，避开原工具的 45210。当前 API 拒绝非回环 Host 和跨站 Origin。Windows 可通过 `start.bat` 启动，服务隐藏运行并打开工具页面。

## 视频与字幕分别保存

新下载自动提取软字幕，生成只含视频/音频的 MP4，以及单独的 SRT。多条字幕按语言和轨道编号分别保存，网页下载记录提供对应文件按钮。文本轨最多导出 8 条，保留同一媒体时间原点；ASS/SSA 转 SRT 时不保留排版特效。

平台网页通过 yt-dlp 下载可用的中英文字幕（包括平台提供的自动字幕）并转换为 SRT。可用 `SUBTITLE_LANGS` 修改语言范围，默认 `en.*,zh.*,-live_chat`。平台需提供可访问的字幕；所有站点都成功并未得到验证。

硬字幕已经成为画面像素，图片字幕也不是文字，无法直接分离成 SRT；页面会说明，当前不包含 OCR 或语音转写。

已有本地 MP4/MKV 的软字幕可以通过以下命令分离，输入原文件保持原样，输出目录必须尚未存在：

```powershell
node scripts/separate-subtitles.mjs "D:\视频\影片.mkv" "D:\视频\影片-分离结果"
```

## 此次修复与验证

- 补齐 IPv4 映射 IPv6 的内网地址拦截。
- 防止其他网页及 DNS 重绑定域名调用本机 API。
- 解析子进程 45 秒超时，下载子进程默认 10 分钟超时。
- 单文件默认上限 500 MiB，未完成任务默认最多 20 个，下载并发保持 2。
- 容量检查包含 yt-dlp 分轨临时文件，并在下载结束时检查最终输出大小。
- 使用明确的 yt-dlp 参数，不读取电脑中可能存在的默认配置。
- 启动不再依赖固定的 K 盘 Node 路径。

测试：`node --test tests/*.test.mjs`。真实媒体验证：`node scripts/test-subtitles-real.mjs`。真实下载验证：`node scripts/smoke.mjs https://你拥有使用权限的公开视频.mp4 report.json [原配套字幕.srt]`，提供字幕文件时逐条比较文字和全部起止时间。

## 导入 Replay 学习

启动本机服务后打开 [Replay 下载页](https://www.replayen.com/download)，输入框、解析结果和下载记录直接显示在网站内，不必打开独立窗口。未连接时点击「重新连接」。内置区域跟随 Replay 的浅色/深色主题，并按内容自动调整高度。下载完成后点击记录中的「导入 Replay 学习」，MP4 和全部配套 SRT 会一起进入学习台。独立打开工具时，同一按钮也可打开 Replay 接收页。

文件只在本机工具和浏览器之间传递，不上传到网站服务器。内置区域使用 credentialless iframe；新版服务限制可嵌入的 Replay 来源，不向网站开放跨站 API。使用支持此浏览器功能的 Chrome/Edge；连接失败时可先分别保存 MP4/SRT，再从 Replay 下载页手动选择导入。默认本机端口必须为 45211；其他端口仍可使用独立下载与保存功能。

Replay 优先使用现有双语字幕。中英文独立字幕的每一句起止时间全部相同时才合并；时间不同则先载入英文并保留原字幕供手动切换。

## 公共服务器版本的条件

当前源码还不是面向公众的服务器版本。公网发布需要常驻下载服务、用户任务与文件隔离、服务器鉴权、出站请求防护、总磁盘/流量限制及 HTTPS 接入。Vercel 页面无法直接运行 Windows 的 exe、操作访客电脑的下载目录，或代替常驻下载进程。

现有 URL 检查不能保证 FFmpeg/yt-dlp 后续重定向、分片请求和 DNS 变化始终安全，因此不能当作服务器出站防护。浏览器验证复用的个人配置不能用于公共服务。

电脑版通过本机伴随工具接入网站。手机可导入已下载的视频和字幕；访客和手机直接在线下载仍需要另外部署服务器版本。
